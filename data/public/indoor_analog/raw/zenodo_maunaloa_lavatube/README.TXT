README

Multi-year temperature and humidity time series from ice caves on Mauna Loa, Hawaii


DESCRIPTION
Air temperature and humidity time series from data loggers in two lava tube caves on Mauna Loa, Hawaii 2011-2017.


CONTENT

Context information for each data logger:
      loggers_summary.csv

Data logger time series:
   Mauna Loa Icecave
      h679_mlic.dat
      n300_mlic.dat
      n301_mlic.dat
   Arsia Cave, Branch A
      h670_arsiaA.dat
      h814_arsiaA.dat
      n302_arsiaA.dat
   Arsia Cave, Branch B
      h815_arsiaB.dat
      h816_arsiaB.dat
      n184_arsiaB.dat
      n624_arsiaB.dat
      n625_arsiaB.dat

Quantities and units are given in file headers. Missing values are assigned -999.


NOTE
A description of Mauna Loa Icecave is provided in Pflitsch et al. (2016). Arctic, Antarctic, and Alpine Research 48, 33-43. Arsia Cave is described in Teehera et al. (2018). Geomicrobiology Journal 35, 227-241 and Schorghofer et al. (2018). Bulletin of the American Meteorological Society, in press.
